# Rock Paper Scissors Game

A simple, fun Rock Paper Scissors game made with basic HTML, CSS, and plain JavaScript. You can play directly in your browser against the computer, track scores live, and hit reset whenever you want to start over.

## Features

- **Interactive UI:** Clickable icons for Rock, Paper, and Scissors.
- **Random Computer Moves:** Uses JavaScript's `Math.random()` to pick the computer's turn randomly.
- **Live Score Tracking:** Keeps track of wins for both you and the computer as you play.
- **Clear Result Messages:** Shows who won each round with green for a win and red for a loss.
- **Reset Button:** Easily resets the scores to 0-0 at any time.

## Built With

- **HTML5:** Game layout and basic structure
- **CSS3:** Flexbox layout, dynamic hover effects, and RGBA styling
- **JavaScript (ES6):** Game rules, event listeners, and DOM updates

1. Clone or download this repository to your computer.
2. Open `index.html` in any web browser (Chrome, Edge, Firefox, Safari).
